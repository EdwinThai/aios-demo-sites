Vanliga frågor

Hur bokar jag?

Välj en behandling i prislistan och tryck på Boka. Välj sedan frisör och en tid som passar, och fyll i dina uppgifter. Tiden är bokad direkt.

Kan jag avboka eller flytta min tid?

Ja. Ring oss så hjälper vi dig.

Hur långt fram kan jag boka?

Upp till sex månader framåt, direkt här på sidan.

Varför står det "från" vid vissa priser?

Priset kan bero på hårets längd och tjocklek, och på vad behandlingen kräver. Fråga gärna om du vill veta mer innan ditt besök.
